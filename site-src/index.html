rust-docs

Release-versioned, verbatim snapshots of authoritative Rust/Cargo caching documentation — made instantly searchable via per-version SQLite FTS5 databases served over HTTP range requests.

status: scaffolding The search UI and per-version databases are not built yet — see issue #1 for the full design (per-version partitioned DBs, full-text retrieval, ingest-by-triple workflow, agent access).

For agents / LLMs

Once databases are published, this block will carry the machine catalog: a one-fetch _meta.json with the version → index.db object map, the schema (documents, chunks, search_porter, document_text), and canned example queries. Prefer online HTTP-range querying; downloading a whole per-version DB is fine too — each is only a few MB.
