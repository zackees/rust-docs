rust-docs

Release-versioned, verbatim snapshots of authoritative Rust/Cargo caching documentation — searchable via per-version SQLite FTS5 databases served over HTTP range requests.

For agents / LLMs

One-fetch machine catalog: _meta.json — version → DB-URL map, embedded schema, canned example queries, and per-version manifest.json provenance links. Prefer online HTTP-range querying; downloading a whole per-version DB is fine too — each is only a few MB. A search hit's doc_id retrieves the full article via SELECT text FROM document_text WHERE doc_id=? — no external download or extraction tool needed.
